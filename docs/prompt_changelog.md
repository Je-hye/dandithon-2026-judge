# 심사 에이전트 시스템 프롬프트 변경 내역

## 2026-10-18 — v1 아이디어 단계 문구 수정

**파일**: `judge.py` (루트, Streamlit Community Cloud 배포본)  
**함수**: `get_judge_response` → `system_prompt`

**변경 전**
```
주의: 아이디어 설명 단계이므로 실제 구현 여부를 알 수 없는 항목(배포, 코드 품질 등)은 계획의 현실성으로 평가합니다.
```

**변경 후**
```
주의: 아이디어가 확정된 단계입니다. 제시된 기획 내용을 바탕으로 평가하며, 배포·코드 품질 등 아직 구현되지 않은 항목은 계획의 구체성과 실현 가능성으로 평가합니다.
```

**이유**: 팀들의 아이디어가 확정됨. 탐색 단계가 아닌 확정된 기획 기반 평가로 전환.
